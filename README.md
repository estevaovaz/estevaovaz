## 👨‍💻 Sobre mim

Desenvolvedor **.NET com mais de 6 anos de experiência**, criando soluções robustas, escaláveis e elegantes — do banco de dados à interface.

- 🏥 Atuo na **Unimed Leste Fluminense**, com C#, Blazor, Entity Framework, Oracle PL/SQL, SQL Server e JavaScript em sistemas críticos de saúde.
- 🚀 Crio e mantenho meus próprios **produtos SaaS** para profissionais da saúde: o **ecossistema PsicoMost**.
- 🤝 Acredito em colaboração, aprendizado contínuo e código limpo.
- 📫 Aberto a novos desafios que unam tecnologia e impacto real.
